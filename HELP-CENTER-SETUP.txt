KCMSC HELP CENTER PATCH

Included
- Public bilingual Help Center: /en/help and /bn/help
- Search across questions, answers and categories
- Topic filters, expandable answers and featured questions
- Admin article management at /admin/help
- English and Bangla question/answer fields, categories, URL slug, publish/draft and featured controls
- 30 answered entries from FAQ.docx imported as drafts for review

INSTALL
1. Back up the current project and database before applying changes.
2. Extract this ZIP into the root of the current project, preserving folder paths and allowing the included files to merge/replace.
3. Stop the Next.js dev server.
4. Run: node scripts/apply-help-center.cjs
   This creates the HelpArticle table and indexes idempotently. It does not reset or delete existing data.
5. Run: npx prisma generate
6. Run: npx tsx scripts/seed-help-center.ts
   This imports the FAQ entries as drafts. Existing HelpArticle records with matching slugs are updated with the supplied FAQ wording, but their publish status is not changed.
7. Run: npm run dev
8. Open /admin/help, review every answer, then publish the entries approved by the school.
9. Check /en/help and /bn/help.

IMPORTANT
- Do not run prisma migrate reset or prisma db push as part of this patch.
- A migration SQL file is included for migration-history documentation, but given the project's existing pending migration history, use the idempotent apply script above for this immediate setup.
- FAQ.docx contains no usable answer for question 27 and the extracted text does not include question 8. Those entries are not seeded.
- English answers are translations of the supplied Bangla text. Fee policies, counts, timings, and contact practices should be confirmed by KCMSC before publishing.
- No AI chatbot or AI API key is included; this is the Help Center-first implementation.
